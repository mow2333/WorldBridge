虚空维度

虚空维度

全称 DIMENSIO_VANITATIS（拉丁文，vanitas = 虚空），背景名遗忘之世界。 一块「是你的世界，但又不是」的镜像世界——地形与主世界完全相同，但那里没有白天，也没有人。

📦 基础信息

属性 值
注册 id world_bridge:dimension_vanitatis
显示名 虚空维度
背景名 遗忘之世界
维度类型 world_bridge:void_night（专属）
时间 永夜，fixed_time = 18000（午夜）
睡眠 ❌ 不可
世界之锚传送 ❌ 不可（4 处入口全部拒绝）
地形 与主世界完全相同（同噪声设置 / 同群系分布 / 同地表高度）

🔧 永夜

走的是原版维度类型机制，不是每 tick 去改时间：

  • 专属 DimensionType world_bridge:void_night，fixed_time = 18000 → 时间真正静止，月亮不动
  • fixed_time 只能冻结时间流逝，拦不住睡觉——玩家睡成功后 ServerLevel#tick 里会把时间直接赋值
  • 因此睡觉单独拦 PlayerSleepInBedEvent，用 NOT_POSSIBLE_HERE 拒绝
  • 没有关 bed_works——关了床会爆炸，那不是想要的效果
  • 6 语言各配一句诗意提示（「虚空已忘年，永夜不逢晨。独汝长无寐，孤灯伴此身。」）

🏚️ 结构腐坏

主世界的村庄 / 矿井 / 遗迹在这里一律是废墟：

变化 说明
坍塌 50% 方块直接消失
风化 石砖长苔 / 开裂，木板换深色橡木（陈旧色）
破碎 玻璃碎裂
熄灭 火把熄灭

⚠️ 带 BlockEntity 的方块一律保留（箱子 / 告示牌 / 刷怪笼）——否则箱子战利品注入就落空了。

村庄类实体不生成：村民 / 僵尸村民 / 铁傀儡 / 猫 / 流浪商人全部拒绝。 牲畜（马 / 牛 / 羊）保留——废墟里有野化动物合理，有村民不合理。

为什么不能事后清理：生成期 WorldGenRegion#getEntities 直接返回 Collections.emptyList()， 查不到实体。只能在实体入世那一刻拦。

💎 战利品

虚空里所有箱子都会追加：

物品 粒度 概率
虚空之锭 每个格子 3%
升级模板 每个箱子 10.3%

注意两者粒度不同：虚空锭按格抽，升级模板按箱抽。

🚪 进入方式

路线 A：凿开世界根（主动）

  1. 用世界根钥核导航，找到可破坏基岩
  2. 在基岩上方放置世界根裂解器
  3. 把钥匙嵌套进去 → 基岩被破坏，露出虚空
  4. 跳进虚空 → 开始持续扣血
  5. 血量剩半颗心（1 HP）时 → 传送进虚空维度

路线 B：掉虚空（被动）

  • 在主世界（非末地）掉下虚空 → 同样持续扣血 → 血量剩半颗心时传送进虚空
  • 末地的虚空不触发（照常死亡）

掉虚空扣血：每次 2 HP / 每 4 tick，满血到半颗心约 2 秒。 为什么单次扣这么多：只缩小间隔压不过饱食度的自然回血。

⚖️ 虚空维度规则

规则 说明 例外
玩家完全无法攻击生物 左键无效 虚空杀手附魔
生物能攻击玩家，且无视任何盔甲防御值 护甲不生效 虚空保护附魔
「虚空生物」定义 虚空维度里所有生物 —

进入惩罚：如果任何一件装备没有虚空保护附魔：

惩罚 数值
移速 -20%
攻击值 -30%

🛏️ 出生点 · 出口 · 死亡

项 说明
出生点 水平坐标 = 主世界出生点 × 10~100（随机）；Y 用与世界之锚同源的「寻找落点」扫描法
出口 虚空维度的出生点（只判定 xz），右键使用钥匙（不需要核心嵌套），返回主世界 64×64 内随机一点
死亡 回主世界重生点（不是虚空重生点）；虚空方块 / 物品无法带回
重置 可破坏基岩重置——旧漏洞补上，重新在 64×64 区块里随机选一块
