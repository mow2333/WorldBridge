    常用命令¶

    📋 命令总览¶

    命令 权限 说明
    /worldbridge create OP 2 创建新维度
    /worldbridge world create <dimId> <typeAndJson> OP 2 命令行创建指令维度（含内联 JSON 全参数）
    /worldbridge world tp <targetDim> [player] [x y z] OP 2 传送，世界桥维度需提供坐标
    /worldbridge world list OP 2 列出所有已创建维度
    /worldbridge world edit <pairId> OP 2 编辑维度配置（GUI）
    /worldbridge world rename <pairId> <name> OP 2 重命名维度
    /worldbridge world delete <pairId> OP 3 删除维度（需确认）
    /worldbridge world resetpassword <pairId> OP 2 重置维度密码
    /worldbridge reload OP 2 热重载服务端配置
    /worldbridge redlink pair list OP 2 列出所有红链配对
    /worldbridge redlink pair disconnect <pairId> OP 2 解除指定配对
    /worldbridge redlink pair locate <pairId> OP 2 定位配对位置
    /worldbridge redlink trigger list OP 2 列出所有以太触发器
    /worldbridge redlink trigger info <pos> OP 2 查看触发器详情
    /worldbridge redlink trigger clear <pos> OP 2 清除触发器区域
    /worldbridge redlink trigger setregion <pos> OP 2 设置触发器检测区域

    权限等级：OP 2 = op-permission-level=2，OP 3 = op-permission-level=3（服务端 server.properties 设置）

    📖 详细用法¶

    /worldbridge create¶

    /worldbridge create <name> <worldType> [options...]

    详见 首次创建维度

    /worldbridge world create <dimId> <typeAndJson>¶

    命令行直接创建指令维度，支持内联 JSON 全参数配置。

    参数： - <dimId> —— 维度 ID（字母数字下划线，如 myworld、nether_2） - <typeAndJson> —— 世界类型 + 可选 JSON 配置，如 default{"name":"MyWorld","difficulty":"hard"}

    # 创建默认维度
/worldbridge world create myworld default

# 创建混沌深渊，自定义名称和难度
/worldbridge world create chaos chaos_abyssos{"name":"真正的混沌","difficulty":"hard"}

# 使用自定义模板
/worldbridge world create custom_world custom:mytemplate

    JSON 可配置字段：name、seed、biome、structures、difficulty、dim_type、generation（sea_level/surface_block/stone_block...）、stacking（min_y/max_y）、gameRules、spawnSettings、visual、effects、respawn

    /worldbridge world tp <targetDim> [player] [x y z]¶

    传送指定玩家（或自己）到目标维度，世界桥维度间传送需提供坐标。

    参数： - <targetDim> —— 完整维度 ResourceLocation，如 world_bridge:a3f2b1c4、minecraft:the_nether - [player] —— 可选，目标玩家名，默认自己 - [x y z] —— 可选坐标（来源或目标涉及世界桥维度时必填）

    坐标规则： - 来源或目标任意一侧是 world_bridge: 维度 → 必须提供 x y z（否则弹出坐标输入界面） - 两边都是原版 minecraft: 维度 → 不需要坐标

    # 传送自己到自定义维度（需提供坐标）
/worldbridge world tp world_bridge:a3f2b1c4 ~ ~ ~

# 传送 Steve 到下界（不需要坐标，因为两边都是原版维度）
/worldbridge world tp minecraft:the_nether Steve

# 从主世界传送到世界桥维度（需要坐标）
/worldbridge world tp world_bridge:chaos 0 64 0

    关键点： - 必须使用完整 ResourceLocation（namespace:path），不能用维度名称或 PairID - Tab 补全包含：原版维度 + 所有已创建 WorldBridge 维度 - 自动寻找安全落点（避开基岩、岩浆、虚空） - 跨维度传送自动加载目标维度 - 坐标可用 ~ 相对坐标

    /worldbridge list¶

    列出所有已创建维度。

    Dimensions (3):
  1. MyWorld (pair: a1b2c3d4) [default] LOADED 1 players
  2. VoidIsles (pair: e5f6g7h8) [aetherial_fields] UNLOADED
  3. SecretAbyss (pair: i9j0k1l2) [chaos_abyssos] LOADED 0 players [PASSWORD]

    状态说明： - LOADED — 维度已加载在内存中 - UNLOADED — 维度未加载（传送时自动加载） - [PASSWORD] — 有密码保护

    /worldbridge edit <pairId>¶

    打开 GUI 编辑维度配置（名称、难度、结构、海平面、密码等）。

    不可修改：PairID、世界类型、种子、生物群系（创建后锁定）

    /worldbridge rename <pairId> <newName>¶

    重命名维度。

    /worldbridge rename a1b2c3d4 NewWorldName
    • 新名称不能与现有维度重复
    • PairID 不变，传送命令、锚点绑定不受影响

    /worldbridge delete <pairId>¶

    永久删除维度（需二次确认）。

    /worldbridge delete a1b2c3d4
# 提示: Are you sure? This cannot be undone. Type the pairId to confirm:
a1b2c3d4

    删除内容： - 维度数据文件（worldbridge_dimensions.dat 条目） - 维度世界文件夹（saves/<world>/dimensions/<pairId>/） - 所有锚点绑定、玩家传送记录

    ⚠️ 不可恢复，操作前请备份世界！

    /worldbridge redlink¶

    红链系统指令，管理无线红石配对与以太触发器。

    子命令：

    子命令 说明
    pair list 列出所有红链配对（pairId、类型、维度、坐标）
    pair disconnect <pairId> 解除指定配对
    pair locate <pairId> 定位配对位置（维度 + 坐标）
    trigger list 列出所有以太触发器及其类型
    trigger info <pos> 查看指定位置触发器的详细配置
    trigger clear <pos> 清除指定位置的触发器
    trigger setregion <pos> 设置触发器的检测区域（两次右键选择角点）

    详细原理和用法见 红链无线红石系统

    /worldbridge reload¶

    热重载 worldbridge-server.toml 配置，无需重启服务器。

    /worldbridge reload
# Reloaded config: 13 entries updated.

    /worldbridge resetpassword <pairId>¶

    重置维度密码（OP 专用，不需旧密码）。

    /worldbridge resetpassword a1b2c3d4
# Password for dimension 'MyWorld' has been cleared.

    新密码可通过 /worldbridge edit 或下次传送时设置。

    🔑 权限速查表¶

    命令 最低 OP 级别 说明
    world create 2 创建指令维度
    world tp 2 传送（可传送他人，世界桥维度需坐标）
    world list 2 查看列表
    world edit 2 编辑配置
    world rename 2 重命名
    world delete 3 删除维度（高危）
    world resetpassword 2 重置密码
    reload 2 热重载配置
    redlink pair list 2 列出红链配对
    redlink pair disconnect 2 解除配对
    redlink pair locate 2 定位配对
    redlink trigger list 2 列出触发器
    redlink trigger info 2 查看触发器
    redlink trigger clear 2 清除触发器
    redlink trigger setregion 2 设置触发器区域

    建议：普通管理员给 OP 2，仅服主/最高管理给 OP 3。

    💡 实用技巧¶

    • Tab 补全：维度名称、世界类型、生物群系均支持 Tab 补全
    • Tab 补全维度：输入 /worldbridge world tp 后按 Tab 显示所有维度（原版 + 自定义）
    • 批量传送：/worldbridge world tp @a world_bridge:a1b2c3d4（需命令方块/函数）
    • 坐标提示：传入/传出 world_bridge: 维度时，如果未提供 x y z，会自动弹出坐标输入界面
    • 查看 PairID：/worldbridge world list 查看 PairID，再用 world_bridge:<pairId> 传送
