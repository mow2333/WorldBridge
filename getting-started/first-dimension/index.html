    首次创建维度¶

    🎮 两种创建方式¶

    方式 适用场景 优点
    GUI 界面 新手、可视化配置 所见即所得、参数有提示、可预览
    命令行 服主、自动化、批量 可脚本化、适合批量创建、无需打开 GUI

    🖥️ GUI 创建¶

    1. 打开创建界面
    2. 聊天栏输入 /worldbridge create

    3. 或在主菜单点击 "WorldBridge" 按钮（需模组加载完成）

    4. 填写基础信息 | 字段 | 必填 | 说明 | |------|------|------| | 维度名称 | ✅ | 显示在列表、传送提示中，建议 2-16 字符 | | PairID | ✅ | 自动生成 8 位十六进制，不可修改 | | 世界类型 | ✅ | 下拉选择 8 种类型之一 | | 生物群系 | 视类型 | 单一生物群系类型必填 |

    5. 高级设置（可选）

    6. 种子 —— 留空随机，指定则固定地形
    7. 难度 —— Peaceful / Easy / Normal / Hard
    8. 生成结构 —— 开启/关闭村庄、要塞、废弃矿井等
    9. 海平面 —— -64 ~ 255，默认 63

    10. 洞穴/矿脉/旧版随机 —— 开关

    11. 密码保护（可选）

    12. 勾选 "Enable Password"
    13. 设置 4-16 位密码

    14. 传送时需输入正确密码

    15. 点击 "Create & Teleport"

    16. 服务端后台创建维度（约 3-10 秒）
    17. 自动传送到新维度安全落点
    18. 聊天栏提示 Created dimension <name> (pairId: xx)

    ⌨️ 命令行创建¶

    基础语法¶

    /worldbridge create <name> <worldType> [options...]

    完整参数表¶

    参数 简写 必填 说明
    <name> - ✅ 维度名称
    <worldType> - ✅ default amplified flat single_biome caves aetherial_fields deep_abyss chaos_abyssos
    --biome <biome> -b 单一群系必填 如 minecraft:meadow
    --seed <seed> -s - 长整数，留空随机
    --difficulty <diff> -d - peaceful easy normal hard
    --structures <true/false> -st - 默认 true
    --sea-level <int> -sl - -64 ~ 255
    --caves <true/false> -c - 默认 true
    --ore-veins <true/false> -ov - 默认 true
    --legacy-random <true/false> -lr - 默认 false
    --password <pwd> -p - 4-16 位，留空无密码
    --difficulty-lock <true/false> -dl - 锁定难度不可改

    示例¶

    # 创建一个默认世界
/worldbridge create MyWorld default

# 创建单一生物群系（繁花丘陵），指定种子
/worldbridge create FlowerWorld single_biome --biome minecraft:meadow --seed 123456789

# 创建混沌深渊，设密码
/worldbridge create SecretAbyss chaos_abyssos --password secret123

# 创建星界之野，关闭结构
/worldbridge create VoidIsles aetherial_fields --structures false

    ✅ 创建后验证¶

    # 查看所有维度
/worldbridge world list

# 传送到刚创建的维度（世界桥维度需提供坐标）
/worldbridge world tp world_bridge:a3f2b1c4 ~ ~ ~

# 查看维度详情
/worldbridge world info <pairId>

    ⚠️ 常见坑¶

    问题 解决
    World type 'xxx' not found 检查世界类型拼写，区分大小写下划线
    Biome required for single_biome 单一生物群系类型必须加 --biome
    Password too short/long 密码长度 4-16 字符
    创建后传送失败 查看日志 latest.log，通常是安全落点扫描超时，可尝试 --seed 指定种子

    💡 小技巧¶

    • 批量创建：写脚本循环调用 /worldbridge create，配合 --seed 固定地形
    • 模板复用：先用 GUI 创建一个满意的，用 /worldbridge info <name> 导出参数，再用命令行批量复制
    • 备份种子：重要维度记下种子，万一世界损坏可用种子重建
