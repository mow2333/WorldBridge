    红链系统 — 无线红石信号总线¶

    版本：0.2.0 基于 Redlink 核心逻辑完整移植，跨维度零延迟无线红石信号传输。

    概述¶

    红链系统提供跨维度、零延迟、同 tick 的红石信号传输。通过红链扳手配对两个红链方块，发射器端的红石信号变化会瞬间同步到接收器端，即使它们在不同维度。

    核心方块（5 种）¶

    红链方块 (redlink_block)¶

    单方块双模式，核心信号传输方块：

    模式 注册名 功能
    发射器 (Input) output_mode=false 每 tick/邻居变化读取六面红石信号最大值 → 同步给对端接收器
    接收器 (Output) output_mode=true 收到对端信号 → 六面全输出该强度
    • 用红链扳手右键切换模式
    • FACING 状态控制模型朝向（不影响信号读取/输出）

    红链按钮 (redlink_button)¶

    • 右键发出 15 强度信号，自动复位
    • 类似原版按钮，但信号强度固定为 15

    红链拉杆 (redlink_lever)¶

    • 右键切换持续 15 强度信号
    • 类似原版拉杆，但信号强度固定为 15

    红链压力板 (redlink_pressure_plate)¶

    • 实体站立发出 15 强度信号
    • 类似原版压力板，但信号强度固定为 15

    以太触发器 (ether_trigger_block)¶

    高级触发器方块，支持 5 种触发类型：

    类型 说明
    PLAYER 玩家进入区域时触发
    ENTITY 任意实体进入区域时触发
    ITEM 物品进入区域时触发
    TIMER 按可配置间隔（20-256 tick）周期性触发
    WEATHER 天气变化时触发
    • 区域检测：用红链触发工具两次右键设定区域角点
    • 客户端 GUI（TriggerSelectionScreen）配置触发类型和参数

    物品（4 种）¶

    物品 注册名 功能
    红链扳手 redlink_wrench 配对工具：右键配对/切换模式
    红链触发工具 redlink_trigger_item 以太触发器配置工具
    红链方块物品 redlink_block 常规方块物品
    各红链源方块物品 redlink_button/lever/pressure_plate 常规方块物品

    配对系统¶

    配对流程¶

    1. 手持红链扳手 → 右键点击方块 A → 扳手记录选择（音效 + 提示）
2. 再右键点击方块 B → 自动配对：
   - 生成随机 pairId
   - 双向写入 pairedPos/pairedDimension/pairId
   - 播放配对音效、发送聊天提示
3. 已配对再次点击同对端 → 解除配对
4. 已配对点击其他方块 → 提示"已配对"

    活跃配对索引¶

    // 静态 Map，跨维度 O(1) 查找
Map<Integer, List<PairEntry>> ACTIVE_PAIRS;
// pairId -> [(pos, dim), ...]

    NBT 持久化¶

    配对数据通过 NBT 全量持久化： - paired_x、paired_y、paired_z — 对端坐标 - paired_dimension — 对端维度（如 world_bridge:cmd_xxx） - pairId — 配对唯一 ID - signal_strength — 当前信号强度

    信号传递逻辑（零延迟、同 tick）¶

    发射器 → 接收器¶

    1. 发射器侧：readInputSignal() 读六面取最大值
2. signalStrength 变化 → setBlock(POWERED) → syncClient()
3. 调用对端 evaluateSignal() → 接收器侧更新 signalStrength
4. 接收器 setBlock(POWERED) → 六面输出 → syncClient()

    跨维度核心实现¶

    跨维度零封装、零代理、零网络包：

    步骤 实现 效果
    存 ResourceKey<Level> → NBT 字符串 跨存档/重启持久化
    取 server.getLevel(ResourceKey) 维度未加载 → 自动同步加载
    传 直接跨 Level 访问方块实体 同 tick 零延迟，无网络包开销 
    // 跨维度获取对端 Level（自动加载）
private static Level getPairLevel(Level level, RedlinkBlockEntity rbe) {
    if (rbe.pairedDimension != null && !rbe.pairedDimension.equals(level.dimension())) {
        if (level instanceof ServerLevel sl) {
            return sl.getServer().getLevel(rbe.pairedDimension);
        }
        return null;
    }
    return level;
}

    关键点：Server.getLevel(ResourceKey) 内部会自动同步加载维度，无需手动调用传送或发包。

    兼容的触发源¶

    • 红石粉、红石块、红石火把、红石比较器
    • 红石火把、红石灯、活塞、发射器、投掷器
    • 方块实体（比较器输出、漏斗、乐器方块等）
    • 模组红石（通过 level.getSignal() 统一获取）

    指令系统¶

    /worldbridge redlink¶

    worldbridge
└── redlink
    ├── pair list                    # 列出所有配对
    ├── pair disconnect <pairId>     # 解除配对
    ├── pair locate <pairId>         # 定位配对
    ├── trigger list                 # 列出以太触发器
    ├── trigger info <pos>           # 查看触发器详情
    ├── trigger clear <pos>          # 清除触发器区域
    └── trigger setregion <pos>      # 设置检测区域

    坐标格式¶

    <pos> := <dimensionId> <x> <y> <z>
例：world_bridge:cmd_abc 100 64 -200

    网络包（5 种）¶

    包 方向 用途
    RedlinkPairPacket C→S 配对/解除配对请求
    RedlinkModePacket C→S 模式切换
    RedlinkSyncPacket S→C 信号强度/配对状态同步
    RedlinkListPacket S→C /wb redlink list 数据
    C2STriggerSelectPacket C→S 触发器选择/配置

    服务端配置¶

    在 worldbridge-server.toml 的 [redlink] 段：

    [redlink]
enabled = true                    # 总开关
max_pairs = 10000                 # 全服最大配对数
allow_cross_dimension = true      # 允许跨维度
auto_load_target_dimension = true # 目标维度自动加载
pairing_tool = "worldbridge:redlink_wrench"  # 配对工具ID

    音效（4 种）¶

    注册名 用途
    PAIR 配对成功
    UNPAIR 解除配对
    SELECT 选择方块
    CLEAR 清除配置
    AMBIENT_LAB 环境音效（预留）

    双分支差异¶

    点 1.19.4 1.20.1
    ResourceKey<Level> ResourceLocation ResourceKey.create()
    Level 获取 server.getLevel() 同
    方块实体渲染 BlockEntityRenderer + PoseStack BlockEntityRenderer + GuiGraphics
    网络缓冲区 FriendlyByteBuf 同
    核心文件数 20 源文件 21 源文件（含 BiomeGroup.java）

    核心逻辑 100% 共用，仅渲染/注册层分文件。
