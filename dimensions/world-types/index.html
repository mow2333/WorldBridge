    三大核心世界类型详解¶

    WorldBridge 原创 3 大核心维度类型，各具特色的生成器与玩法体验。

    🌌 混沌深渊¶

    属性 值
    类型 ID chaos_abyssos
    生成器 RuinedChunkGenerator(CHAOS_ABYSSOS)
    噪声类型 Amplified (放大化)
    特殊群系概率 1/73

    🌋 地貌特色¶

    • 生物群系混合：主世界 7 种群系（玄武岩三角洲、绯红森林、诡异森林、下界荒地、灵魂沙谷、末地、末地高地、末地中部、末地荒岛、末地群岛）按 1/73 概率随机替换原版群系
    • 地貌变形：Chunk 级整体抬升/下沉（±48 格）、细节扭曲、尖塔生成、切片空洞、陨石坑、裂隙
    • 天空废墟：原版 NBT 结构（末地船、要塞、堡垒遗迹、古代城市）在 Y=120+ 随机生成
    • 地表崩坏方块：区块级噪声判定，约 50% 区块每区块生成 2-6 个崩坏方块于地表

    🏗️ 天空结构¶

    结构 来源 生成高度
    末地船 minecraft:end_city Y≥120
    要塞 minecraft:stronghold Y≥120
    要塞遗迹 minecraft:bastion_remnant Y≥120
    古代城市 minecraft:ancient_city Y≥120

    通过 StructureTemplateManager 加载原版 NBT 模板，不手搭。

    🌸 星界之野¶

    属性 值
    类型 ID aetherial_fields
    生成器 RuinedChunkGenerator(AETHERIAL_FIELDS)
    固定群系 minecraft:meadow (繁花丘陵)
    噪声来源 minecraft:amplified (放大化)

    🌤️ 核心机制¶

    • Y<100 全部虚空：生成时将 Y<100 所有方块设为空气，形成纯净虚空层
    • Y≥100 放大化地形：继承 minecraft:amplified 噪声设置，极限山峰、深谷、悬浮岛
    • 完整洞穴/矿脉/旧版随机：完整支持原版洞穴生成、矿脉分布、旧版随机种子兼容
    • 海平面可配：默认 Y=63，但 Y<100 已清空，实质海平面在 Y≥100 处

    🏝️ 视觉体验¶

    • 脚下是无尽虚空（Y<100）
    • 头顶是耸入云端的繁花山峰（Y≥100）
    • 适合：空岛生存、建筑展示、 Elytra 飞行、摄影

    🕳️ 幽邃深渊¶

    属性 值
    类型 ID deep_abyss
    生成器 标准 NoiseBasedChunkGenerator
    固定群系 minecraft:deep_dark
    重做内容 维度类型、地形高度、天花板、海平面

    🕳️ 重做详情¶

    项目 数值/设置
    维度类型 hasCeiling=true、hasSkylight=false、logicalHeight=128
    视觉效果 主世界天空/雾/光照（无下界雾/热量）
    火无限燃烧 infiniburn_overworld
    世界高度 Y=0 ~ 127 (minY=0, height=128)
    顶层天花板 自动生成不规则基岩天花板 (Y=127)
    默认方块 石头
    默认流体 水
    海平面 -64 (无水海/岩浆海)
    群系 固定 minecraft:deep_dark

    🏗️ 生成器设置¶

    {
  "type": "minecraft:noise",
  "generator": {
    "type": "minecraft:noise",
    "settings": "minecraft:overworld",
    "biome_source": {
      "type": "minecraft:fixed",
      "biome": "minecraft:deep_dark"
    }
  }
}

    使用主世界噪声设置 (minecraft:overworld)，仅固定群系为 Deep Dark。

    📊 三维度对比速查¶

    维度 适合玩法 难度 特色资源 危险等级
    混沌深渊 探索、寻宝、建筑、摄影 ⭐⭐⭐⭐ 稀有群系、天空结构战利品、崩坏方块 ⭐⭐⭐⭐ (地貌极端、虚空风险)
    星界之野 空岛生存、建筑、Elytra、摄影 ⭐⭐ 浮空岛地形、虚空风景 ⭐⭐ (虚空落下、高空缺氧)
    幽邃深渊 地下探险、深暗生存、红石、摄影 ⭐⭐⭐ 深暗生物群系、深层板岩、感应体 ⭐⭐⭐ (守卫者、黑暗效应、天花板限制)

    🔧 创建命令示例¶

    # 混沌深渊
/worldbridge create MyChaos chaos_abyssos --seed 12345

# 星界之野
/worldbridge create MyAether aetherial_fields

# 幽邃深渊
/worldbridge create MyDeep deep_abyss

    所有核心维度类型不需要指定 --biome（固定群系）。
