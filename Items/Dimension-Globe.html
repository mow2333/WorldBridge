维度地球仪

维度地球仪

📋 基本信息

属性 值
注册名 world_bridge:dimension_globe
堆叠数 1
稀有度 常见（蓝色材质）
硬度 1.5
声音 紫水晶

🔧 获取方式

配方 图案 产出
3×3 有序合成 
GGG
RAR
SSS
 维度地球仪 ×1

键位：G = 玻璃，R = 红石粉，A = 世界之锚，S = 荧石粉

🖱️ 使用方式

放置维度地球仪后右键点击打开「维度链路地球仪」界面；管理员也可直接使用指令 /worldbridge world map 打开（等效入口）。

地球仪将维度网络以原生 3D 力导向图可视化：

  • 节点：每个维度一个节点，按维度类型区分形状（圆形 / 菱形 / 十二边形 / 方形 / 六角星 / 六边形）
  • 连线：连接线样式区分连接类型（实线 / 宽实线 / 虚线 / 细虚线），跨维漏斗连线带流光粒子动画
  • 轨道相机：拖动旋转视角、滚轮缩放、右键平移

维度类型与节点样式

类型 颜色 形状 说明
主世界 绿 圆 原版维度
下界 橙 菱形 原版维度
末地 紫 十二边形 原版维度
自定义 蓝 方形 WorldBridge 自建维度
指令 黄 六角星 指令创建的维度
外部 灰 六边形 其它模组创建的维度（如暮色森林）

外部维度节点自动连一条到主世界的虚线边；OP 可见全部维度（含未加载），普通玩家只看已加载维度。

界面操作

操作 效果
左键点击节点 选中 → 相机平滑飞向节点聚焦；点击空白取消选中恢复视角
右键点击节点 弹出菜单：传送至维度 / 复制 ID / 删除维度
搜索框 输入关键词实时筛选节点与连线
图例 点击切换各维度类型的显示/隐藏
滚轮 / 双击 手动接管相机（清除聚焦动画目标）

界面保持打开时每 30 秒自动原地刷新维度数据（不重开界面），刷新间隔可在服务器配置调整。

⚙️ 服务器配置

配置键 类型 默认值 说明
globe.enabled bool true 开启维度链路地球仪（方块 + /worldbridge world map）
globe.metrics_interval int 30 界面数据自动刷新间隔（秒，5–300）

配置文件：worldbridge-server.toml → [globe] 段

🧭 小贴士

  • 地球仪需要 OP 权限 才能使用（数据收集按 OP 过滤）
  • 右键菜单的「传送」走 /worldbridge world tp 指令通道，权限与回滚逻辑保持一致
  • 创建维度时记录「父维度」信息，地球仪上呈现父 → 子的连接方向（旧存档数据无父维度信息时回退显示为主世界连接）
  • 外部维度（其它模组创建，如暮色森林）：显示为灰色六边形并连向主世界；普通玩家只看到已加载的外部维度
