    更新日志¶

    格式：版本号 — 发布日期 — 变更摘要
    详见 CHANGELOG.md 完整历史

    0.2.0 — 待发布¶

    ✨ 新增¶

    • 指令创建维度：/worldbridge world create <dimId> <typeAndJson> 命令行创建，支持内联 JSON 全参数覆盖
    • 自定义维度模板系统：JSON 模板 CRUD + GUI 管理界面，支持 biome_mix 群系混合
    • 红链无线红石系统：5 种方块 + 配对工具 + 跨维度零延迟信号传输
    • 玩家可见红字错误提示：全链路异常反馈

    🔧 修复 (1.19.4)¶

    • 坐标要求规则扩大：现在任何 world_bridge: 命名空间维度（含非 cmd_ 前缀）都触发坐标输入要求
    • CustomDimensionManager 新增 isWorldBridgeDimension() 方法
    • WorldBridgeCommand.teleport()/TeleportHelper 阻断改用新方法

    0.1.3e — 2026-07-17¶

    ✨ 新增¶

    • Wiki 完整重构：MkDocs Material 主题、双语 (EN/ZH)、GitHub Pages 部署
    • FEATURES.md 同步更新：新增 14 大功能模块文档
    • 成就系统全英文化：EN/ZH 双语言文件完整同步
    • 更新日志拆分：CHANGELOG_EN.md / CHANGELOG_CN.md 双文件
    • AGENTS.md 新增「内心独白用中文」规则

    🔧 修复¶

    • 创造模式物品栏崩溃 (The stack count must be 1) —— 补 CORRUPTED_BLOCK BlockItem
    • 混沌深渊地表崩坏方块生成概率调整为 ~50% 区块 / 2-6 个/区块
    • 1.19.4 ResourceLocation.parse() 运行时崩溃 → 全量替换为 new ResourceLocation(ns, path)
    • 种子交换静默失效修复：引用比较 f.get(worldData) == expected
    • 成就 Toast 不显示兜底机制 ModTrigger.awardDirectly() 优化
    • 星锚动态光源并发安全：CopyOnWriteArraySet 替换 HashSet
    • 移除所有节流日志 (logThrottled)，消除启动器崩溃隐患

    📚 文档¶

    • Wiki 结构重组：首页、快速开始、维度、物品、成就、配置、进阶、FAQ
    • 双语更新日志：EN/ZH 完整对应
    • TODO.md 精简为「未实现 + 已知 Bug」仅两类

    0.1.3d — 2026-07-16¶

    ✨ 新增¶

    • 幽邃深渊重做：洞穴式结构、Y=0~127、基岩天花板、海平面 -64
    • DimensionType 重做：hasCeiling=true、hasSkylight=false
    • NoiseSettings 复用主世界噪声 + 固定 Deep Dark 群系

    🔧 修复¶

    • 深渊维度传送失败 (Y=-64 安全落点扫描)
    • 混沌深渊特殊群系 1/73 概率实测偏低问题缓解

    0.1.3c — 2026-07-15¶

    🌟 星锚动态光源修复¶

    • 并发修复：StarAnchorLightManager.dirtyChunks → CopyOnWriteArraySet
    • 光照叠加修复：Math.max(blockLight, boosted) 保留原版光源
    • 实体渲染光照：新增 EntityRendererMixin 拦截 BlockAndTintGetter.getBrightness
    • 清理调试日志：移除所有 logThrottled、计数器字段

    🔧 并发修复¶

    • LayerLightSectionStorage.getStoredLevel NPE → Mixin @Redirect 空检查返回 0
    • 种子交换静默失效 → 引用比较修复

    0.1.3b — 2026-07-14¶

    🔐 密码功能完全实现¶

    • 维度创建/编辑时可设密码 (4-16 字符)
    • 传送验证流程：TeleportPacket → OpenPasswordScreenPacket → PasswordScreen → VerifyPasswordPacket → 服务端 SHA-256 比对
    • OP 重置：/worldbridge resetpassword <pairId>
    • 翻译键全覆盖：8 个密码相关 key (中英双语)
