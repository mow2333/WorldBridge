开发者 API（0.5.0）

开发者 API（0.5.0）

WorldBridge 从 0.5.0 起提供公开 API：接口 / 事件 / 数据类放在独立仓库 https://github.com/mow2333/WorldBridge-API（MIT），实现由主 mod 闭源提供。 本页面向想要把 WorldBridge 作为库 / 依赖集成的模组开发者。

API 总览

系统 门面 事件 服务接口 说明
维度 WorldBridgeAPI WorldBridgeEvents IWorldBridgeService 维度数据 CRUD / 传送 / LevelStem 生成
红链 RedlinkAPI RedlinkEvents RedlinkService 信号查询 / 断连操作；配对、断连、信号变化事件
跨维漏斗 HopperAPI HopperEvents HopperService 配对状态 / 吞吐查询；配对、断连、传输事件
维度地球仪 GlobeAPI — GlobeService 只读查询维度网络节点 / 边

所有门面位于 com.mow.mod.worldbridge.api 包，事件经 Forge 事件总线发布。

支持版本

  • Minecraft 1.19 ~ 1.20.4 共 10 个版本（Forge 41.0.68+ ~ 49.1.0+）
  • API 仓库每个版本一个独立工程目录（1.19/ … 1.20.4/），按对应 MC/Forge 编译

依赖方式

// build.gradle — 将对应版本 API jar 作为 compileOnly 依赖
dependencies {
    // 推荐：从 WorldBridge-API 仓库克隆对应版本目录后编译，或直接用 release jar
    compileOnly files('libs/worldbridge-api-0.5.0-1.20.1.jar')
}

运行期请确保 WorldBridge 主 mod 已安装（实现由此提供，API 模块本身不含实现）。

调用约定

所有门面采用服务定位模式：主 mod 加载后自动注册服务实现。调用前先确认服务可用：

import com.mow.mod.worldbridge.api.WorldBridgeAPI;

if (WorldBridgeAPI.isServiceAvailable()) {
    // 安全调用，如：获取全部维度数据
    Collection<DimensionData> dims = WorldBridgeAPI.getAllDimensions(serverLevel);
}

若服务未注册（主 mod 未加载）而强行调用，门面会抛出 IllegalStateException。

监听事件

生命周期事件通过 Forge 事件总线发布，用 @SubscribeEvent 监听：

import com.mow.mod.worldbridge.api.RedlinkEvents;
import net.minecraftforge.eventbus.api.SubscribeEvent;

public class MyListener {
    @SubscribeEvent
    public void onPair(RedlinkEvents.RedlinkPairEvent event) {
        int pairId = event.getPairId();
        // event.getPosA() / getPosB() / getDimensionA() / getDimensionB() ...
    }

    @SubscribeEvent
    public void onSignal(RedlinkEvents.RedlinkSignalEvent event) {
        // event.getOldStrength() -> event.getNewStrength()
    }
}

事件清单：

事件类 触发时机
WorldBridgeEvents.DimensionCreateEvent 维度数据创建前（可取消）
WorldBridgeEvents.DimensionRemoveEvent 维度数据删除前（可取消）
WorldBridgeEvents.DimensionUpdateEvent 维度数据更新后
WorldBridgeEvents.PlayerTeleportEvent 玩家传送至 WB 维度前（可取消）
RedlinkEvents.RedlinkPairEvent 红链配对建立
RedlinkEvents.RedlinkUnpairEvent 红链配对断开
RedlinkEvents.RedlinkSignalEvent 红链信号强度变化
HopperEvents.HopperPairEvent 跨维漏斗配对建立
HopperEvents.HopperUnpairEvent 跨维漏斗配对断开
HopperEvents.HopperTransferEvent 物品跨维传输成功

数据类

API 仓库附带纯数据类（无实现逻辑），可直接用于读写维度配置：

类 说明
DimensionData 维度全参数（含 AnchorPoint 锚点）
GenerationConfig / PermissionSettings / GameRuleConfig 维度生成 / 权限 / 游戏规则配置
GlobeData（含 Node / Edge） 维度网络快照

扩展维度生成器（可选）

附属 mod 可实现 IDimensionFactory 并注册，接管特定 dimType 的维度生成：

import com.mow.mod.worldbridge.api.IDimensionFactory;
import com.mow.mod.worldbridge.api.DimensionFactoryRegistry;

DimensionFactoryRegistry.register(new IDimensionFactory() {
    @Override public ResourceLocation getId() { return new ResourceLocation("myaddon", "void_world"); }
    @Override public boolean matches(DimensionData data) { return "void_world".equals(data.dimType); }
    @Override public LevelStem createStem(MinecraftServer server, DimensionData data) { /* ... */ }
});
